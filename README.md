# 📜 Калькулятор клановых бафов — Dead Impact

Удобный веб-калькулятор для планирования гильдейских усилений в игре **Dead Impact**. Инструмент помогает быстро подсчитать итоговую стоимость выбранных бафов и справедливо распределить сбор крышек между участниками клана.

🔗 **[Открыть калькулятор](https://userimp.github.io/Clan-BuffsDeadImpact)**

## ✨ Основные возможности

* **Гибкий выбор усилений:** отмечайте нужные бафы по отдельности или выберите все в один клик.
* **Учёт ранга клана:** расчёты подстраиваются под текущий уровень вашей гильдии.
* **Распределение вкладов:** укажите количество меценатов, чтобы узнать точную сумму крышек с одного участника или при групповом сборе.
* **Контроль казны:** автоматический расчёт остатка крышек, который пойдёт в фонд клана.
